Installing

  1. Tap the button above and confirm the download.
  2. Open the downloaded file. Android will ask to allow installs from this source — allow it.
  3. If Play Protect warns about an unknown developer, choose More details, then Install anyway.
  4. Open Vaani and grant microphone, contacts, phone and SMS, then turn on Screen control in Accessibility.
Why Play Protect warns: this app is signed with a developer key, not distributed through the Play Store. That is normal for software installed directly from a project page.
